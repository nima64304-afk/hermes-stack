🔑 GitHub access

You need a Personal Access Token with repo and workflow scopes so the wizard can create your repo and set its secrets.

1

Open this pre-filled link — the token creation page opens with the right boxes ticked. Give it a name, pick an expiration, then click Generate token.

2

Copy the token (ghp_…) and paste it below. It stays in your browser only.

🔒 This wizard is a static file; tokens are sent only to api.github.com, huggingface.co and api.telegram.org — nowhere else. When the deploy finishes, revoke/rotate this token on GitHub (good hygiene).

🤗 Hugging Face token

A token with the write role is needed to create the Space, upload files and set the Space secrets.

1

In token settings, create a new token with the Write role (or a fine-grained token with Write access to Contents).

Your app's final address will look like this: https://USER-hermes-stack.hf.space

💬 Telegram bot

In Telegram, open @BotFather, send /newbot, and paste the token (123456:AA…) here. You can also skip this step entirely.

For “Fetch from chats”: first send /start to your bot in Telegram (or any message), then click the button — the wizard lists recent senders; click one to allow them. This locks the bot so only you can use it.
